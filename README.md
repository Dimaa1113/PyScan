# Cython Port Scanner (Русская версия)

Невероятно быстрый полноценный сканнер портов на Cython, разработанный в качестве Python библиотеки и утилиты командной строки.

## Особенности

- Сканирование одного IP-адреса
- Сканирование диапазона IP-адресов
- Сканирование списка IP-адресов и/или диапазонов
- Основной движок сканирования написан на Cython для максимальной производительности
- Совместимость с Pydroid (arm64)
- Интерфейс командной строки (CLI)

## Установка

### Стандартная установка (с помощью pip)

Предполагается, что у вас установлен Python и pip. Cython и C-компилятор также необходимы для сборки из исходного кода.

```bash
pip install cython # Если еще не установлен
# pip install . # Если вы клонировали репозиторий
# Или когда будет опубликован: pip install cython-port-scanner-ru
```

### Pydroid (Android arm64)

Эта библиотека разработана с учетом совместимости с Pydroid 3 на архитектуре arm64.

Для установки в Pydroid:
1.  Убедитесь, что у вас установлен Cython: откройте терминал в Pydroid и выполните `pip install cython`.
2.  Убедитесь, что в Pydroid доступна среда для сборки C-компилятором. Обычно Pydroid предлагает установку "NDK" (Native Development Kit) или "build-essential" репозитория, который предоставляет Clang и другие необходимые инструменты. Проверьте настройки Pydroid или менеджер репозиториев.
3.  После настройки среды сборки, вы можете установить библиотеку (когда она будет доступна на PyPI или из локального клона):
    ```bash
    # pip install cython-port-scanner-ru
    # или из локального клона:
    # pip install /path/to/cloned/repository
    ```

Если возникают проблемы при сборке в Pydroid, убедитесь, что ваш Pydroid обновлен, и все необходимые компоненты для сборки (Cython, NDK/Clang) установлены корректно.

## Использование

### Как библиотека Python

```python
from port_scanner import scan_single_port, scan_multiple_ports, scan_ip_range_ports, scan_ip_list_ports

# Пример сканирования одного порта
is_open = scan_single_port("192.168.1.1", 80)
print(f"Порт 80 на 192.168.1.1 {'открыт' if is_open else 'закрыт'}")

# Пример сканирования нескольких портов
open_ports = scan_multiple_ports("192.168.1.1", [80, 443, 8080])
print(f"Открытые порты на 192.168.1.1: {open_ports}")

# Пример сканирования диапазона IP
results_range = scan_ip_range_ports("192.168.1.1-192.168.1.5", [22, 80])
for ip, ports in results_range.items():
    print(f"IP: {ip}, Открытые порты: {ports}")

# Пример сканирования списка IP/диапазонов
results_list = scan_ip_list_ports(["8.8.8.8", "192.168.1.100-192.168.1.102"], [53, 80])
for ip, ports in results_list.items():
    print(f"IP: {ip}, Открытые порты: {ports}")

```

### Через интерфейс командной строки (CLI)

После установки пакета, утилита `cython-port-scanner-ru` будет доступна в терминале.

**Примеры:**

- Сканировать один IP, один порт:
  ```bash
  cython-port-scanner-ru --ip 192.168.1.1 -p 80
  ```

- Сканировать один IP, несколько портов:
  ```bash
  cython-port-scanner-ru --ip 192.168.1.1 -p 80,443,8080
  ```

- Сканировать один IP, диапазон портов:
  ```bash
  cython-port-scanner-ru --ip 192.168.1.1 -p 1-1024
  ```

- Сканировать диапазон IP, несколько портов:
  ```bash
  cython-port-scanner-ru --ip-range 192.168.1.1-192.168.1.10 -p 22,80,443
  ```

- Сканировать список IP и диапазонов, несколько портов:
  ```bash
  cython-port-scanner-ru --ip-list "192.168.1.1,10.0.0.5-10.0.0.10,8.8.8.8" -p 53,80
  ```

Для получения полной справки:
```bash
cython-port-scanner-ru --help
```
